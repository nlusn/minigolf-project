`Mini-golf OpenGL Project`

Team:
  Sagi Alpyssov 
  Anatoliy Tsoy
  Nargiza Kuzybahova

Description:
   This project will feature mini-golf game with one golf hole, a mill, and a golf ball that will have physical features of acceleration, speed, and so on. Mill will be moving too, it will rotate its sails, which will block the movement of a ball.


Technologies used:
   OpenGL
   Glad
   GLM
   ...
